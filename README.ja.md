# X Ambient

[English](README.md) · [Español](README.es.md) · 日本語 · [ダウンロード](https://github.com/mmnga/x-ambient/releases/latest)

XとInstagramの画像・動画、TwitchとKickの配信の色をぼかして、ページの背景全体にアンビエントライトを広げるChrome拡張です。投稿の詳細では開いたポストが自動で点灯し、Xのタイムライン・返信はホバーで切り替わります。Instagramはアクティブな投稿・リールへ自動で追従します。Manifest V3、ビルド不要、依存パッケージ不要。

![デモ画像](docs/images/preview.png)

画像の縁の色が放射状に広がり、左右の余白や他の投稿カードも染めます。元の画像・動画・アバターはくっきり残ります。プレビューは、このリポジトリに含まれるデモ素材を使用しています。

## Chromeに読み込む

1. [Releases](https://github.com/mmnga/x-ambient/releases/latest) から `x-ambient.zip` をダウンロードし、解凍する。
2. Chromeで `chrome://extensions` を開き、右上の「デベロッパーモード」を有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` があるフォルダを選ぶ。
4. 対応サイトを再読み込みする。Xでは投稿詳細を開くか、タイムライン・返信にホバーする。Instagramでは通常のフィード・リールを表示する。Twitch・Kickでは動画や配信を再生する。

このリポジトリをダウンロードして、そのフォルダをChromeへ読み込むこともできます。インストールにNode.jsは不要です。

更新時は、同じフォルダに新しいファイルを置き、拡張管理画面の更新ボタン（↻）を押して対応サイトも再読み込みします。

拡張のアイコンから、オン・オフ、強さ、ぼかし、広がり、動画への追従を変更できます。設定は端末内に保存し、開いている対応サイトのタブへ反映します。

Xの「強さ」は、0%で元のテーマ色、100%で画像・動画の端の色をそのままぼかした背景になります。彩度を上乗せせず、強さを上げるほど元のメディア色に近づきます。

「Xのカードを画面幅に合わせる」は標準でOFFです。ONにすると、ホバーしていない投稿も含めて、カードと画像・動画の幅をウィンドウの表示領域に合わせます。文字・アイコンのサイズとメディアの縦横比は保ちます。ウィンドウを広げるとカードも広がり、狭めると横にはみ出さない幅に縮まります。ON・OFFはその場で反映されます。左右のカラムを残し、横幅が足りない場合はXの右側の補助カラムを隠してカードの表示領域を確保します。

- **ページの背景全体**（標準）: 左右の余白、タイムラインの中央、ホバー中と他の投稿カードの背景も含めて、ページ全体へ色を広げます。表示中の画像・動画・アバターはマスクして、そのままくっきり残します。狭いウィンドウでも全背景に適用します。
- **投稿の周囲**: ホバー中の投稿の周囲だけへ光を広げる表示も選べます。
- 投稿詳細では、開いたポストの画像・動画がホバーなしで点灯します。返信・コメントはホバーで切り替え、ホバーが外れると開いたポストに戻ります。画面外のメディアは対象外です。
- Instagramではホバーなしで、画面中央の投稿・リールへ自動追従します。十分に見えている再生中の動画を優先し、カルーセルは表示中の画像だけを使います。スクロール・画像の切り替え・一時停止に対応します。
- Xのタイムラインではホバーが外れるとフェードアウト。画像のない投稿やアバターだけの投稿では表示しません。
- 画像・動画の実際の位置を起点に、各辺の色が外側へ放射状に伸びてぼけます。「広がり」で遠くまで届く光の強さを調整できます。
- 縦長の動画が横長の枠に入っている場合も、余白を除いた映像の縁から上下左右へ光を広げます。
- 複数画像を配置どおりに合成。動画は最大12fpsで表示中のフレームに追従し、停止・シークにも対応します。
- スクロール、追加された投稿、Xのページ内遷移に対応。非表示のタブ、全画面再生、対象のメディアがない間は描画を停止します。
- ダーク・ライト表示に対応。OSの「視差効果を減らす」設定では、動画の連続更新とフェードを止めます。

## インストール前に試す

Node.js 22以上で以下を実行し、表示されたローカルURLを開きます。

```sh
npm run demo
```

デモは `http://127.0.0.1:4318`。実際の拡張と同じ描画コードを使い、画像・動画・複数画像・テキスト投稿を試せます。`Ctrl+C` で終了します。ポートを変更する場合は `X_AMBIENT_DEMO_PORT=4320 npm run demo`。

## 開発と検証

```sh
npm run check
npm test
```

`manifest.json` はそのままChromeへ読み込めます。`src/content.js` が対象の選択・動画の更新・マスク、`src/instagram.js` がInstagramのアクティブ投稿の選択、`src/ambient-core.js` が合成と配置、`src/popup.*` が設定画面です。変更後は拡張管理画面の更新ボタンを押し、対応サイトのタブも再読み込みしてください。

配布用のフォルダとZIPは `npm run package` で作れます。`output/x-ambient` をChromeへ読み込むか、`output/x-ambient.zip` を解凍して読み込みます。ZIPには拡張の実行ファイル、MITライセンス、インストール手順を含めます。

自動チェックとReleaseの作成方法は [CONTRIBUTING.md](CONTRIBUTING.md) を参照してください。

## メディアと権限

対応サイトに表示済みの画像・動画を、小さなCanvasに `drawImage()` で写してCSSでぼかします。動画の複製再生や動画ファイルの追加ダウンロードは行いません。未再生動画は、利用できる場合にサムネイルを表示します。

外部メディアを描いたCanvasは読み出しが制限されるため、ピクセルの読み出し・書き出しを使わず、Canvas自体を表示します。[MDN: drawImage](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/drawImage)、[MDN: 外部画像とCanvas](https://developer.mozilla.org/en-US/docs/Web/HTML/How_to/CORS_enabled_image)。

権限は設定保存の `storage` と、コンテンツスクリプトを動かすX/Twitter、Instagram、Twitch、Kickのページアクセスのみ。画面キャプチャ・全サイトへのアクセス・外部サーバーへの送信はありません。

Instagramの対応範囲は通常のフィードとリールです。ストーリーズ・DM・プロフィールの一覧は対象外です。サイトのDOM構造が変わると、メディアを検出するセレクターの更新が必要になることがあります。暗号化されている動画など、ブラウザがCanvasへの描画を許可しないメディアには対応しません。

## 言語と配信サイトの対応

日本語・英語・スペイン語・韓国語・中国語（簡体字／繁体字）・タイ語・ベトナム語・インドネシア語・フランス語・ドイツ語・ポルトガル語（ブラジル／ポルトガル）・イタリア語・ロシア語・アラビア語・ヒンディー語に対応しています。拡張の言語設定では、ブラウザの言語を自動で使用するか、言語を手動で選択できます。中国語は地域・文字種から簡体字と繁体字を判定し、手動選択を優先します。ポルトガル語は地域で判定し、地域指定がない場合はブラジル版を使用します。アラビア語は右から左へ表示します。

TwitchとKickでは、画面内で最も大きい動画の色に自動で追従します。画面外・非表示の動画、全画面表示、クロスオリジンの埋め込み動画は対象外です。ビルドにはNode.jsの標準モジュールのみを使用し、外部のzipコマンドは不要です。
